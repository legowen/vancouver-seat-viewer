# Vancouver Seat Viewer

Pick a seat at a Metro Vancouver Cineplex theatre and see the screen from it before you book.

> Unofficial fan project — not affiliated with Cineplex Entertainment.

This README is filled in as the build progresses; see `PROGRESS.md` for the current state and
`docs/spec.md` for the full brief.

## Run it locally

```bash
npm install
```

```bash
npm run dev
```

Then open the address Vite prints (it ends in `/vancouver-seat-viewer/`).

## Checks

```bash
npm run lint
```

```bash
npm test
```

```bash
npm run build
```
